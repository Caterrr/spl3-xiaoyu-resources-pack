# 模型清单核对

核对范围是《斯普拉遁 3》与当前提供的 10.1.0 资源，不包括其他作品新增的敌人

## 已核对的清单

| 分类 | 当前结果 | 范围与限制 |
| --- | --- | --- |
| 旧武器、新武器 | 173 / 173 套对战武器有对应条目 | 用武器数据库 ID 与原模型对应表核对，保留原有熊牌等额外模型，未重复导出已验证的武器 |
| 技能 | 14 项副武器都有静态表示，其中地雷在装饰栏 | 地雷摆件不等于运行时技能效果；部分特殊武器需要运行时材质或玩家模型，不能把独立部件当完整技能 |
| 地图 | 26 个对战场景条目、14 个鲑鱼跑场景条目均有对应 | 含祭典与大型跑的数据库条目；85 个任务/世界条目有对应，模板 MsnParent 不作为可游玩地图 |
| 场景 | 已对照 267 条场景数据，并复用已有原坐标装配核验 | 当前资源缺少 122 个秩序篇场景引用的基础布局；DLC 广场仅有部分节庆层，不能视为完整广场 |
| 杂物 | 保留 254 个此前验证的完整条目 | 复用 1227 项源物件的完整性分类；百科没有覆盖所有地图物件的完整总表，不能据此宣称所有杂物齐全 |
| 角色 | 从 50 项增加到 104 项 | 首轮补入 26 项，本轮补入 28 个完整水母 NPC，保留原有条目 |
| 装饰 | 475 / 475 项储物柜摆件有对应模型 | 对照百科与原始 LockerGoodsFigureInfo 的模型引用；此数字不代表所有运行时调色组合已重建 |

## 本次新增

鲑鱼部分补入运金鲑鱼、金鲑鱼、母舰的小型敌人和泥鲑鱼主体

其余补入已确认完整的商店角色、裁判、司令、Acht 等独立模型，未恢复零碎配件或驾驶舱散件

泥鲑鱼和运金鲑鱼采用原始待机动画首帧，并按原 FBVS 显隐骨选择可见主体

泥鲑鱼内置的吐出小鱼和破坏碎片在 Blender 中保留为隐藏对象，GLB 只交付可见主体；这属于静态主体展示，不代表完整游戏运行逻辑

新增交付已独立重开 Blender 和 GLB，检查网格、UV、材质、内嵌贴图及空间位置；新旧原文件保留不覆盖

## 尚未补齐

后续按用户要求先处理现有资源，不等待 DLC 原始文件

本轮补回 28 个有完整原始 Actor 归属的水母 NPC；两种格式均独立重开，检查 UV、内嵌贴图与位置，并核对源文件哈希，未恢复灰白的祭典变体和零碎部件

金泥鲑鱼已读取原始 WaitGold 材质动画，并生成独立本地样本，但主体颜色仍不正确，样本未上架

DLC 逐项缺失记录见 [DLC 待补清单](DLC待补清单.md) 和 [CSV](DLC待补清单.csv)，包含 122 条秩序篇场景引用、两个广场基础布局与两个商店场景；场景引用含楼层及模式变体，不等于相同数量的不同地图

- 荧光棒水母：原始粗糙度贴图引用未解析，当前暂不展示
- 潜水鱼：Main / Fin 的完整连接与显隐关系仍不确定，不硬拼
- 金泥鲑鱼：待机主体已在本地导出，但金色运行时材质尚未确认，不上架当前错误颜色
- 帝王乌贼两个形态：完整原网格可用，但当前导入遗漏队伍色着色，预览发白，暂不恢复
- 部分偶像角色：原始头发/队伍色遮罩未完整转换，暂不恢复错误颜色
- 玩家等模块化角色、部分首领：不能用未经确认的服装、状态或附属件拼出完整角色
- 秩序篇关卡与 DLC 广场：需要对应的原始基础布局资源，不能用节庆层或其他地图代替

这是一份有明确检查范围和待补项的记录，网站尚未达到所有类型全部齐全
